# Use one versioned Blackboard v2 Project Interface

Blackboard v2 exposes one closed semantic contract through seven trusted tools—change, atomic Attempt result, current read, history, Evidence retention, Attempt checkpoint, and finish—and path-versioned `/api/v2` HTTP adapters with the same service semantics. The atomic Attempt result tool is a constrained composition of the same semantic service operations. It records one tested result without a repeated read/change loop. HTTP uses honest status codes, bearer/daemon authentication, `Idempotency-Key`, revision ETags, and cursor-paginated history; Runtime MCP payloads never accept Project, Task, Continuation, or origin identity. A common optional synchronization attachment lets the next authenticated trusted response carry the complete new Runtime Blackboard Snapshot even when the attempted semantic operation fails validation. This replaces the graph-v1 tool/route catalog instead of maintaining compatibility aliases, trading a deliberate breaking cutover for one small, predictable interface that can evolve only additively within v2.

## v2 defect correction: one legal Evidence write path

The generic `blackboard_change` tool cannot create Evidence. `blackboard_retain_evidence` is the only legal Evidence create or replacement path because the server must derive storage and integrity fields. The old Schema advertised generic Evidence creation, but the Go DTO could not decode it. That advertised path was never implementable. Removing it is a v2 defect correction, not a new breaking operation.

Every advertised write input must now pass a Contract-to-DTO parity test. Schema failures use the closed v2 Error Envelope and identify the exact input path, a stable reason, and a next action when one tool must replace another. Tool descriptions and root Schema examples state the high-cost rules: use `transition` for lifecycle changes, add a `tests` relation when a Runtime creates an Attempt, choose exactly one Attempt identity mode, and include a produced target for a succeeded Attempt result.
