现状诊断：6 个核心问题

P1
信息层级平

标题、标签、正文、配置项权重相同，找不到视觉入口

P2
启动页一屏到底

目标输入与 Docker network 等高级项平铺，无渐进披露

P3
Timeline 不可扫读

tool/result 成对占行、时间戳重复、Turn 无分组

P4
Dashboard 空洞

裸数字卡片 + 全 0 scope 格，没有"下一步该做什么"

P5
状态语义靠猜

stopped / offline / unavailable 等 chip 无统一语义色系统

P6
Sidebar 无状态

重名 session 无法区分，看不到哪个 Task 正在运行

Direction A 改动清单

全局 Sidebar — 搜索过滤、Session/Task 活动状态点（绿脉冲=运行中）、重名条目用相对时间区分、分组计数
语义状态 chip 系统 — 生命周期（灰）/ Runtime 活性（绿蓝红）/ 模式（teal）分离，替代随意着色
Timeline 按 Turn 分组 — 左侧轨线 + 标记，tool call 压缩单行、result 折叠、reasoning 可展开、系统事件降级为分割线
启动页三段式 — 目标输入主角化 → 常用 4 项紧凑卡片 → 高级配置手风琴（带值摘要）+ 右侧粘性 Launch 摘要栏
Dashboard 可行动化 — Scope readiness 引导清单、统计卡带状态细分、新增 Recent activity 与 Current work
Composer 状态解释 — 'unavailable' 角标替换为说明横幅：状态 → 后果 → 动作

静态 mockup · Tailwind CDN + Geist 字体 · 设计 token 与 web/src/index.css 生产值一致 · 不影响现有代码
