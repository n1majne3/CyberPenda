# Disabled Blackboard mode

The Runtime has no Blackboard state, API URL, or Continuation Interface token. Do not call Blackboard commands or infer that a Blackboard is available.

Use files in the writable workdir for coordination. Follow any platform-specific Skill, challenge client, clock, and submission instructions provided to the Runtime.
